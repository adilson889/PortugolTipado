Todo programa em PortugolTipado começa obrigatoriamente pela `funcao inicio()`. Os blocos de código são delimitados por chaves `{ }` e não é obrigatório o uso de ponto e vírgula `;` no fim de cada linha.

Os comentários servem para documentar o código e são ignorados pelo compilador.

```portugol
// Este é um comentário de uma linha

/* 
   Este é um comentário
   de múltiplas linhas 
*/

funcao inicio()
{
    escreva("O programa começa aqui!\n")
}
```

# Documentação do PortugolTipado

Aqui está tudo o que precisas para escrever, compilar e distribuir programas em PortugolTipado.

## Por onde começar

- Nunca escreveste em PortugolTipado: lê os capítulos 1 a 8, por ordem. Cada um tem um exemplo para copiar e um exercício no fim.
- Já programas e queres só consultar: usa o [Manual de referência](MANUAL.md).
- Queres lições curtas e soltas: vê os [tutoriais](tutorial/).
